# 点数オセロ — 石に点数がついたオセロ
石の一つひとつに点数がついたオセロ。石の数ではなく、自分の色の数字の合計で勝負します。

## 🔗 リンク
- 遊ぶ: https://sora3141.github.io/score-othello/
- 制作: [T.OF...](https://sora3141.github.io/)

## 遊び方

### ルール
- **丸い石がプラス、角丸の四角い石がマイナス**。石に刻まれたサイコロの目の数が点数
- ふたりとも同じ手駒を持つ（6×6 なら +1〜+4 と −1〜−4 を各2枚、合計0点）。中央の4石は0点
- 手番では手駒を1枚選び、通常のオセロと同じく相手の石をはさめるマスに置く
- はさまれた石は数字はそのままで、色だけが変わる
- **得点 ＝ 盤上の自分の色の数字 ＋ 手元に残った手駒の数字**。スタートは 0 対 0 で、点が動くのは石を返したときだけ
- 相手のマイナスを返すと自分の点が減る。プラスは返されにくい場所へ、マイナスは相手に返させる場所へ
- 置ける場所がなければ自動でパス。両者置けなくなったら終局。同点なら石の多い方が勝ち
- 手駒を使い切ったら 0点の「ブランク駒」を何枚でも使える

| 盤 | 手駒（1人あたり） |
|---|---|
| 4×4 | ±1〜±3 各1枚（6枚） |
| 6×6 | ±1〜±4 各2枚（16枚） |
| 8×8 | ±1〜±5 各3枚（30枚） |

### 機能
- CPU 対戦（やさしい / ふつう / つよい）・ふたり対戦
- 置く前に、返る石と点の増減をプレビュー（ヒント表示で全マスに点の増減を表示）
- 一手戻す、対局の自動保存（端末内の localStorage、キーは `score-othello.*`）、サウンド
- 結果の共有

### 操作
手駒を選んでからマスをタップ（先にマスを選んでから手駒を選んでもよい）。
PC では `1`〜`5` で +の手駒、`Shift`+数字で −の手駒、`0` でブランク駒。`⌘/Ctrl+Z` で一手戻す、`H` でヒント切替。

## アプリとして入れる（PWA）
メニューの「アプリにする」から、ホーム画面やデスクトップに追加できます（iPhone / iPad では Safari の共有 → 「ホーム画面に追加」の手順が表示されます）。
一度開けばオフラインでも遊べます。

## 開発
ビルド不要。`index.html` 1 枚にすべて入っています。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

- `index.html` — アプリ本体
- `sw.js` — オフライン用のサービスワーカー（キャッシュ名は `score-othello-` で始まる）
- `manifest.webmanifest`, `icons/` — PWA 用（`icons/icon.svg` が元絵）
- `webapp-kit/` — 「アプリにする」「共有」ボタン（正本は [sora3141.github.io](https://github.com/Sora3141/sora3141.github.io) の `webapp-kit/`）
